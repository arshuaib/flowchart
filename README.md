# FlowTrack Pro 3.7.0

Single-file browser finance manager.

### Advanced features
- Google Drive synchronization with local/remote merge.
- Income, expense, transfer, lending, loan repayment, custody/disbursement transactions.
- Multi-source disbursements.
- Budgets with monthly usage tracking.
- Savings goals with progress tracking.
- Recurring income/expense schedules with due processing.
- Date-range transaction filtering.
- CSV, JSON, Word and print-to-PDF reporting.
- Analytics, smart financial insights and wallet summaries.
